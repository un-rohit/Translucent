How Translucent Handles Gemini 503 High Demand Spikes

When Google's public endpoints return 503 ServiceUnavailable ("model experiencing high demand") or 429 RateLimit on gemini-3.8-flash, Translucent automatically re-routes the prompt to gemini-2.5-flash in milliseconds.
